Divine Journey 2 Modern - removed CraftTweaker displayName overrides
====================================================================

Scope
-----
18 entries are now handled by the language files in this directory:
- 6 Mithril items (Thermal Foundation), migrated 2026-11-13.
- 12 further items, migrated 2026-11-14 (all displayName overrides except the one
  explicitly excluded below).

Excluded on purpose (user decision):
- extendedcrafting:singularity:21 (Alchemical Brass Singularity)
Its displayName line stays in the .zs scripts (known to be a no-op; fix tracked in TODO.md).

Reason
------
CraftTweaker's `<item>.displayName = "..."` is not a static data change: it calls
LanguageMap.inject("<unlocalized>.name", "<value>") at script load time. Injected
keys are applied after language files are loaded, so they would override the
zh_cn names in this resource domain (and force English on Chinese clients).
To make the names localizable, the lines below were removed and moved to
overrides/resources/itemrenames/lang/{en_us,zh_cn}.lang.
